# 🐎 말 달리는 야근 미터기 (OverTaxed)

> **"택시 미터기처럼 실시간으로 올라가는 야근비!"**  
> 평일 20시부터, 주말·공휴일 언제든! 2배 심야할증 시 말에 불꽃이 붙고 질주하는 레트로 택시 미터기 웹 앱입니다.

---

## ✨ 핵심 기능

1. **🐎 말 달리는 레트로 픽셀 애니메이션**
   - **빈차 상태**: 꼬리를 살랑거리며 대기
   - **정규 야근 (1.5배)**: 경쾌한 도트 말 달리기 모션
   - **심야 / 휴일연장 (2.0배 할증)**: 눈에 불을 켜고 불꽃(🔥)을 뿜으며 초고속 터보 질주!
2. **📟 7-Segment LED 택시 미터기**
   - 실시간 누적 요금 (Share Tech Mono 디지털 LED 폰트)
   - [빈차] / [주행] / [할증 2배] 실제 택시 인디케이터 램프
   - 다음 30분 요금 인상까지 남은 시간 프로그레스 바
3. **⏱️ 완벽한 야근 수당 계산 룰**
   - **기준 시급 설정**: 자유롭게 입력 및 영구 저장 (예: 19,610원)
   - **평일(월~금)**: 20:00~22:00 (1.5배) / 22:00 이후 심야할증 (2.0배)
   - **주말/공휴일**: 시작 시간 무관 8시간까지 (1.5배) / 8시간 초과 이후 (2.0배)
   - **정산 단위**: 30분 단위 정산 (실시간 부드러운 표시 vs 30분 계단식 모드 선택 가능)
4. **📊 수당 장부 & 통계**
   - 오늘 번 돈, 이번 주, 이번 달, 기간별 수입 필터
   - CSV 파일 내보내기 백업 지원
5. **🧾 택시 영수증 모달 & 폭죽 효과**
   - 영업 종료 시 실제 택시 영수증 디자인으로 출력
   - 원클릭 영수증 텍스트 복사 및 모바일 공유
6. **📊 Google Sheets 100% 무료 자동 연동 (옵션)**
   - 구글 계정의 스프레드시트에 야근 기록이 실시간으로 1행씩 자동 누적!
7. **📱 맥, 아이폰, 아이패드 완벽 지원**
   - 반응형 웹 디자인
   - Safari / Chrome **[홈 화면에 추가]** 시 네이티브 앱처럼 풀스크린 작동

---

## 🚀 빠른 시작

### 1. 개발 서버 실행
```bash
npm run dev
```
브라우저에서 `http://localhost:5173` 접속

### 2. 휴대폰 / 아이패드에서 바로 접속하기 (동일 와이파이)
터미널에서 `npm run dev -- --host`를 실행하면 표시되는 로컬 IP (예: `http://192.168.0.x:5173`)로 아이폰이나 아이패드 브라우저에서 접속할 수 있습니다.

---

## 📑 Google Sheets 100% 무료 연동 가이드

1. 본인의 **Google Drive**에서 새 **Google 스프레드시트**를 하나 만듭니다.
2. 상단 메뉴에서 **[확장 프로그램] > [Apps Script]**를 클릭합니다.
3. 기존 코드를 모두 지우고, 앱 내 **[환경설정 ⚙️] > [설정 가이드 & 코드]**에서 제공하는 코드를 복사하여 붙여넣습니다.
4. 오른쪽 위 **[배포] > [새 배포]**를 누릅니다:
   - 유형: **웹 앱(Web app)** 선택
   - 액세스 권한: **모든 사용자(Anyone)** 선택 *(중요)*
5. 생성된 **웹 앱 URL**을 앱 설정창의 Google Apps Script URL 필드에 붙여넣고 저장하면 연동 완료!
6. 이후 야근 종료 시마다 구글 시트에 자동으로 행이 추가됩니다.

## 🌐 무료 온라인 배포 (맥, 아이폰 어디서나 나만의 주소로 접속)

Vercel이나 Cloudflare Pages에 GitHub 저장소를 연결하면 1분 만에 `https://my-overtaxed.vercel.app` 과 같은 무료 도메인으로 배포됩니다.
아이폰 Safari에서 해당 주소로 접속 후 **공유 버튼 > [홈 화면에 추가]**를 누르면 끝!
