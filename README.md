# 🐎 말 달리는 야근 미터기 (OverTaxed)

> **"택시 미터기처럼 실시간으로 올라가는 야근비!"**  
> Mac, iPhone, iPad 어디서나 실시간으로 주행 상태가 동기화되는 레트로 택시 미터기 웹 앱입니다.

---

## 🌟 핵심 기능

1. **🐎 말 달리는 레트로 픽셀 애니메이션**
   - 대기(빈차) ➔ 일반 야근(1.5배) ➔ 심야/휴일연장 터보 질주(2.0배 불꽃🔥) ➔ ☕ 법정 30분 의무 휴식
2. **📟 7-Segment LED 택시 미터기**
   - 실시간 누적 요금 표시 & 실제 택시 인디케이터 램프(`빈차`/`주행`/`할증`/`휴식`/`무급봉사🚨`)
   - 시계 기준 30분 단위 정렬 (:00 / :30 기준 칼같이 정산 카운트다운)
3. **💳 택시 미터기 '통행료 (+30분)' 앞당기기**
   - 늦게 켰을 때 누르면 시작 시각이 직전 30분 단위 정각(예: 4시 44분 ➔ 4시 00분)으로 칼같이 스냅되어 1구간 수당 즉시 합산! (취소 시 100% 원복)
4. **☕ 4시간 근무 시 30분 의무 휴게시간 (근로기준법)**
   - 4시간 연속 근무 시 30분간 요금 상승 일시 정지 & 말이 쉬는 애니메이션 & 남은 휴식 시간 게이지
5. **💸 30분 칼정산 & 자투리 무료 봉사 계산**
   - 30분 단위로 완성된 시간만 정산하고, 못 채운 자투리 시간은 "회사 기부(무료 봉사)" 금액으로 위트 있게 환산!
6. **🚨 주간 한도 관리 & 일요일 자정 초기화**
   - 매주 일요일 00:00에 주간 시간 자동 리셋 & 한도 초과 시 무급 봉사 경보!
7. **🔄 기기 간 실시간 주행 동기화 (Mac ↔ iPhone ↔ iPad)**
   - Mac에서 켜두면 퇴근길 스마트폰에서도 똑같이 말이 달리고 요금이 실시간 상승!
8. **📸 영수증 공유 방식 선택 (Action Sheet)**
   - 🖼️ 영수증 이미지(PNG) 저장, 📱 스마트폰 공유창, 💬 카톡 텍스트 복사, ✉️ 문자 전송 지원
